# JobHub — JavaScript Job Portal

A responsive job portal built with **HTML, CSS and Vanilla JavaScript**.

## Features

- Search jobs by title, skill or keyword
- Filter by location, category, job type, experience and work mode
- Sort by latest, salary and company
- Save/unsave jobs with LocalStorage
- Job details modal
- Application form with LocalStorage persistence
- Demo "Post a Job" feature
- Responsive design for desktop and mobile
- No external framework required

## Tech Stack

- HTML5
- CSS3
- JavaScript (ES6+)
- DOM Manipulation
- LocalStorage

## Run locally

Open `index.html` in a browser, or use VS Code Live Server.
