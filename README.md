# JobHub — JavaScript Job Portal

A responsive and modern Job Portal web application built with HTML5, CSS3 and Vanilla JavaScript.

## 🚀 Live Demo

[View Live Website](https://welcomanujsingh-hash.github.io/jobhub-job-portal/)

## ✨ Features

- 🔍 Search jobs by title, skill or keyword
- 📍 Filter jobs by location
- 💼 Filter by category and job type
- 🎯 Filter by experience level
- 🏠 Remote, Hybrid and On-site work modes
- 🔃 Sort jobs by latest, salary and company
- ❤️ Save and unsave jobs
- 📝 Job application form
- ➕ Post a Job demo
- 💾 LocalStorage support
- 📱 Responsive design for desktop, tablet and mobile
- ⚡ Fast frontend application with no external framework

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript (ES6+)
- DOM Manipulation
- LocalStorage
